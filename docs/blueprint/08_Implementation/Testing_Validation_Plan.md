# Testing and validation
Unit (pure kernels, hand-computed values in the specs), golden regression (tests/golden), property-based (hypothesis: mass balance, monotonicity, non-negativity), oracle tests (raycast for shading, pvlib for PV), twin experiments (recover known parameters; coverage >= 90 % at 95 %), blocked temporal CV for calibration, agent evals (groundedness, refusal, injection), performance tests (N2). Field validation plan: log predicted vs observed for yield, canopy, soil moisture, ECe, SOC (every 1-2 yr), PV kWh (meter), PAR under panels; report skill vs a naive baseline.
